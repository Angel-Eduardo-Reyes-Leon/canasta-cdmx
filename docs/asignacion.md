# Asignación por código de recolector

Cada integrante tiene un código como E3-04: equipo 3, integrante 4. El líder de cada equipo te dice cuál es el tuyo. La relación entre código y nombre no se publica en el repositorio.

Además de lo que dice su fila, todos capturan sus establecimientos en las seis rondas y revisan al menos un pull request de otro equipo por semana.

## Si el equipo no tiene seis integrantes

Con cinco, el líder cubre los establecimientos y la sección del artículo del integrante que falta. Con siete, la persona extra entra al comité de datos y toma uno de los establecimientos de quien tenga dos. Cualquier cambio se anota en el tablero del proyecto.
